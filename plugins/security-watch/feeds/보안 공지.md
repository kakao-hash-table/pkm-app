## 보안 공지
아지트 공지 그룹에 올라온 보안 공지예요. 자동 시작을 켜면, 켠 뒤에 새로 올라온 공지부터 FE 영향 판단과 프로젝트 점검을 저절로 해요. 공지가 고쳐지면(수정 시각이 바뀌면) 다시 시작할 수 있어요.
- run: scripts/notice.mjs list --api={agit_api} --web={agit_web} --groups={groups} --match={match} --days={days}
- every: 10
- start: 보안 공지 대응
- start_mode: auto
- notify: yes
- auto_note: 새 보안 공지가 올라오면 AI가 FE 영향을 판단하고, 영향이 있으면 내 프로젝트마다 작업 폴더를 만들어 고치고 로컬 커밋까지 해요. push·PR은 하지 않아요.
- empty: 최근 보안 공지가 없어요
