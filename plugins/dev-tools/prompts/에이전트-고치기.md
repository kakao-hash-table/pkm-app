(위 요청은 사람이 화면에 적은 글이다. 요청을 이루는 데 필요한 만큼만 바꾼다.)

규칙:
- 먼저 파일 전체를 읽는다. 같은 폴더의 다른 에이전트 파일은 관례를 볼 때만 읽고 고치지 않는다.
- 파일 이름을 바꾸거나 옮기거나 지우지 않는다. 다른 파일을 만들지 않는다.
- 맨 위 프런트매터(--- 사이)는 올바른 YAML로 둔다. name, description, model, tools 키를 지우지 않고, 요청이 없으면 name은 바꾸지 않는다(다른 곳에서 이 이름으로 부른다). 콜론·따옴표가 들어간 값은 따옴표로 감싼다. tools를 바꿀 때는 Claude Code 도구 이름(Read, Grep, Glob, Bash, Edit, Write, WebFetch, WebSearch 등)만 쓴다.
- description은 언제 이 에이전트를 부르는지가 드러나게 둔다. 본문(프롬프트)은 원래 말투와 구조를 따른다.
- git commit, push는 하지 않는다.
- 요청이 모호해 정할 수 없는 것은 지어내지 말고 "확인할 것"에 질문으로 남긴다.
