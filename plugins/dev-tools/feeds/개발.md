## 프로젝트
설정에 적은 프로젝트 폴더예요. 개발 서버를 띄우고 멈추고, 고칠 것을 AI에게 맡기거나 사용성 점검을 받아요.
- run: scripts/projects.mjs list --projects={projects}
- every: 5
- count: no
- start: 띄우기, 멈추기, AI로 고치기, AI 사용성 점검
- empty: 프로젝트가 없어요. 플러그인 설정의 "프로젝트"에 폴더를 적어 주세요

## 에이전트
에이전트 폴더의 Claude Code 에이전트 파일이에요. 고칠 것을 적으면 AI가 그 파일만 고쳐요.
- run: scripts/agents.mjs list --dirs={agent_dirs}
- every: 60
- count: no
- start: AI로 에이전트 고치기
- empty: 에이전트 파일(.md)이 없어요. 플러그인 설정의 "에이전트 폴더"를 확인해 주세요
