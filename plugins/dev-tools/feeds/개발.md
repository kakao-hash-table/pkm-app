## 프로젝트
설정에 적은 프로젝트 폴더와 FE 프로젝트 노트의 로컬 폴더예요. [띄우기]는 묻지 않고 바로 띄워요(명령은 노트의 실행 명령 → 지난번 명령, 포트는 노트의 "포트 N" → 지난번 포트). 다른 명령은 띄운 뒤 [명령 바꾸기]로 골라요.
- run: scripts/projects.mjs list --projects={projects} --fe={fe_group}
- every: 5
- count: no
- view: inline
- start: 띄우기, 멈추기, AI로 고치기, AI 사용성 점검
- empty: 프로젝트가 없어요. 플러그인 설정의 "프로젝트"에 폴더를 적어 주세요

## 에이전트
에이전트 폴더의 Claude Code 에이전트 파일이에요. 고칠 것을 적으면 AI가 그 파일만 고쳐요.
- run: scripts/agents.mjs list --dirs={agent_dirs}
- every: 60
- count: no
- start: AI로 에이전트 고치기
- empty: 에이전트 파일(.md)이 없어요. 플러그인 설정의 "에이전트 폴더"를 확인해 주세요
