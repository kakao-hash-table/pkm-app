## 프로젝트
로컬 프로젝트를 실행하고 중지해요. 명령과 포트를 직접 고르고, 점유 중인 포트와 실행 오류를 같은 카드에서 확인해요.
- run: scripts/projects.mjs list --projects={projects} --fe={fe_group} --proxy={domain_proxy} --legacy={legacy_ports}
- every: 5
- count: no
- view: inline
- start: 띄우기, 멈추기, 포트 종료, Cursor로 열기, AI로 고치기, AI 사용성 점검
- controls: project
- inputs: command, port, pid
- search: 프로젝트 이름·명령·브랜치로 찾기
- empty: 프로젝트가 없어요. 플러그인 설정의 "프로젝트"에 폴더를 적어 주세요

## domain-proxy
fedev 도메인(<이름>-hash.fedev.kakao.com)을 이 컴퓨터의 포트로 잇는 프록시예요. 새 도메인은 [도메인 더하기] 뒤 [fedev 등록]을 눌러야 열려요.
- run: scripts/domain-proxy.mjs list --script={domain_proxy}
- every: 5
- count: no
- view: inline
- start: 프록시 띄우기, 프록시 멈추기, fedev 등록, 도메인 더하기
- empty: 플러그인 설정의 "domain-proxy.js 위치"에 파일 경로를 적어 주세요

## 도메인
domain-proxy.js의 ROUTES예요. 도메인마다 보내는 로컬 포트와, 그 포트로 띄운 프로젝트를 보여요. 고치면 실행 중인 프록시를 다시 띄워요.
- run: scripts/domain-proxy.mjs routes --script={domain_proxy}
- every: 5
- count: no
- view: inline
- start: 포트 바꾸기, 도메인 지우기
- search: 도메인·포트·프로젝트로 찾기
- empty: ROUTES에 도메인이 없어요

## 에이전트
에이전트 폴더의 Claude Code 에이전트 파일이에요. 고칠 것을 적으면 AI가 그 파일만 고쳐요.
- run: scripts/agents.mjs list --dirs={agent_dirs}
- every: 60
- count: no
- start: AI로 에이전트 고치기
- empty: 에이전트 파일(.md)이 없어요. 플러그인 설정의 "에이전트 폴더"를 확인해 주세요
