- [숫자] 숫자 · ask: 예: 12000 정산 2건
- [적기] 장기에 쌓기 · script: scripts/pilot.mjs checkin --pid={pid} --key=manual --value={숫자.answer} --work-root={workspace}

## 다르게 할래요
AI가 이유를 보고 다른 방법을 찾아요. 정할 것과 할 일은 AI에게 보낼 요청을 한 번 더 확인해요.
- ok: 이유 보내기
- [사유] 왜 다르게 하고 싶어요? · ask: 예: 회사 규정상 X 계정은 만들 수 없어요
- [검토] 고칠 요청 정리 · script: scripts/pilot.mjs me-reject --pid={pid} --kind={kind} --ref={ref} --reason={사유.answer} --work-root={workspace}
- [반영] 설계 고치기 · ai when {검토.request}: prompts/반영.md
- [확인] 내 확인 · script when {검토.request}: scripts/pilot.mjs review --pid={pid} --plan={반영._plan} --confirm=yes --work-root={workspace}
- [만들기] 바뀐 것 만들기 · script when {검토.request}: scripts/pilot.mjs build --pid={pid} --why={검토.request} --work-root={workspace}
