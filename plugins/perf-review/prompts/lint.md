# 저장 전에 짚어 줄 꼴. 한 줄에 "정규식 → 안내". '## 이름'은 갈래, 맨 앞 #은 주석
## AI 티
·|ㆍ → 가운뎃점(·)은 AI 티가 나요. 쉼표나 /로 바꿔요
—|– → 대시는 AI 티가 나요. 쉼표를 쓰거나 문장을 나눠요
→|->|⇒ → 화살표 대신 'A에서 B로'처럼 써요
× → 곱하기 기호 대신 '배'나 숫자로 써요
\*\*[^*\n]+\*\* → 굵은 글씨는 제출 칸에 그대로 별표로 들어가요
되어지|되어졌|되어진 → '되어지다'는 겹친 피동이에요. '되다'로 써요
에\s?있어서 → '~에 있어서'는 번역투예요
할\s?수\s?있었습니다 → '~할 수 있었습니다'는 '~했습니다'로 줄여요
진행하였습니다|진행했습니다 → '~를 진행했습니다'는 '~했습니다'로 줄여요
다양한|획기적|혁신적|성공적으로|효율적으로|적극적으로|원활하게|원활한|체계적으로|극대화|시너지 → 빈 꾸밈말이에요. 무엇이 어떻게 달라졌는지로 바꿔요
결론적으로|궁극적으로|이를 통해|이로써|요약하자면 → 정당화 꼬리말이에요. 빼도 뜻이 같은지 봐요
단순히[^.\n]{0,30}아니라|뿐만 아니라|그치지 않고 → 'A가 아니라 B' 대비 틀은 한 글에 한 번까지만
! → 느낌표는 보고 글에 맞지 않아요

## 제출 칸 규칙
[A-Z][A-Z0-9]+-\d+ → 티켓 키는 제출 본문에 쓰지 않아요
\b[01]\d[0-3]\d\s*배포|\d{4}-\d{2}-\d{2}\s*배포 → 배포일은 제출 본문에 쓰지 않아요
PR\s*#?\d+|[a-z][\w-]*#\d+ → PR 번호는 제출 본문에 쓰지 않아요
