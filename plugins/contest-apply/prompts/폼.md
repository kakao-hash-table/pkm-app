## 1. text — 그 문항에 넣을 답
글로 적는 값은 직접 쓰지 말고 **자리표시**로 써. 프로그램이 채워.
- `{{작품}}` 응모작, `{{뜻풀이}}` 응모작의 뜻풀이
- `{{이름}}` `{{연락처}}` `{{이메일}}` `{{생년월일}}` `{{주소}}` `{{소속}}`처럼 응모자 정보는 `{{항목 이름}}`. 네가 값을 모르는 다른 정보도 `{{항목 이름}}`으로 쓰면 프로그램이 응모자에게 물어봐. 한 칸에 여러 정보를 받으면 문항이 요구한 꼴로 이어 써(예: `{{이름}} / {{나이}} / {{사는 곳}}`).
- 뜻풀이와 다른 글을 요구하거나(기획 의도, 활용 방안) 글자 수 제한에 뜻풀이가 안 맞으면 `{{칸 이름}}`으로 두고, extras에 **후보마다** 그 값을 써(cand는 후보 번호, name은 칸 이름). 글자 수 제한과 '규칙'을 꼭 지키고, 요강의 취지에 맞게 구체적으로. 마크다운 기호는 쓰지 마.

유형마다 답을 쓰는 꼴이 정해져 있어. 이 꼴이 아니면 프로그램이 넣지 못해.
| 유형 | 답 |
|---|---|
| 단답 · 장문 | 글 또는 자리표시. 단답은 한 줄. '규칙'(숫자만, 정해진 꼴, 글자 수)이 있으면 맞춰 |
| 하나 고르기 · 목록에서 고르기 | 보기 글을 **글자 그대로** 하나 |
| 여러 개 고르기 | 보기 글을 줄을 바꿔 하나씩. '규칙'에 개수(2개 이상, 3개까지)가 있으면 지켜 |
| 보기에 '(직접 입력)'이 있을 때 | 맞는 보기가 없으면 보기 대신 직접 쓴 글(짧게) |
| 점수 · 별점 · 척도 | 보기에 있는 값 하나(예: `4`) |
| 표에서 고르기 | 행마다 한 줄씩 `행 글 :: 열 글`. 행마다 여러 개를 고르는 표면 같은 행을 여러 줄로 |
| 날짜 | `2026-11-10` 꼴('규칙'에 연도 없이 월-일만이라 하면 `11-10`). 오늘이면 `{{오늘날짜}}`, 생년월일이면 `{{생년월일}}` |
| 시간 | `14:30` |
| 날짜와 시간 | `2026-11-10 14:30` |
| 걸린 시간 | `1:30:00`(시:분:초) |
| 숫자 | 숫자만(예: `3`). 범위가 '규칙'에 있으면 그 안에서 |
| 주소 | `{{주소}}` (상세 주소 칸이 따로 있으면 `{{주소}} | {{상세 주소}}`) |
| 단계별 고르기 | 보기 글을 **글자 그대로** 하나(보기가 `대분류·소분류` 꼴로 묶여 있어) |
| 동의 | 아래 2번 |
| 파일 올리기 | 빈 글. note에 무엇을 올려야 하는지 적어(프로그램은 파일을 올리지 못해) |

## 고르는 법
보기 가운데 무엇을 고를지는 이렇게 정해.
1. **공모전과 응모작으로 정해지는 것은 네가 골라.** 응모 부문·분야·작품 종류는 '공모전'의 받는 작품과 후보에 맞는 보기를, 작품 수는 1을, 응모작이 국문인지 영문인지 같은 것은 후보를 보고 골라.
2. **응모자 조건으로 정해지는 것은 네가 골라.** 연령대·출생 연도·성별·사는 지역·신분(일반/대학생/직장인)·참가 자격 확인은 위 '응모자 조건'에 맞는 보기를 골라. 나이는 '공모전'의 오늘 날짜와 생년월일로 계산해(생일이 연도뿐이라 보기의 경계에 걸리면 고르지 말고 3번처럼).
3. **응모자만 아는 것은 추측하지 마.** 의견·만족도·경험·참여 횟수·팀원·추천인처럼 위 자료로 알 수 없는 것은 `{{짧은 항목 이름}}`으로 써. 프로그램이 보기를 보여 주며 응모자에게 물어봐.
4. 어디서 알게 됐는지 묻는 문항은 '공모전'의 찾은 곳(공모전 모음 사이트)에 맞는 보기를 고르고, 맞는 보기가 없고 직접 입력이 되면 그 사이트 이름을 써.
5. 해당하는 사람만 쓰는 선택 문항(만 14세 미만의 법정대리인 정보, 단체·팀 응모 정보, 소속 기관이 있는 경우)은 빈 글로 둬.
6. 필수가 아닌 홍보·마케팅·소식 수신 동의는 빈 글로 둬(동의하지 않음).
7. 답에 따라 다른 문항으로 넘어가는 폼이면, 네가 고른 답으로 가게 되는 문항만 채우고 나머지는 빈 글로 둬.

## 2. consent
유의사항 확인, 개인정보 수집·이용 동의, 제3자 제공 동의, 저작권 동의, 참가 서약, 연령 확인처럼 응모자의 **의사 표시**를 받는 문항이면 true. text에는 동의·확인한다는 뜻의 보기 글을 그대로 써(동의 날짜면 `{{오늘날짜}}`, 서명 대신 이름을 적으라면 `{{이름}}`). 프로그램이 응모자에게 따로 물어보고, 동의한다고 할 때만 그 답을 넣어. 아니면 false.

## 3. format
연락처를 '- 없이 숫자만' 적으라는 문항이면 `digits`, 아니면 빈 글.

extras는 `{{칸 이름}}`을 썼을 때만, 후보 전부에 대해 써. 없으면 빈 배열.
note: 응모자에게 할 말 한 줄(예: 응모작이 문항의 글자 수 제한을 넘는 후보가 있음, 올려야 할 파일). 없으면 빈 글.
