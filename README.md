# pkm-app

노트, 하루 시간표, 할 일을 한 화면에서 다루는 개인 지식관리(PKM) 웹 앱입니다. 노트는 Obsidian과 함께 쓸 수 있는 마크다운 파일로 저장됩니다.

Node 20 이상만 있으면 바로 띄울 수 있습니다. 노트는 이 저장소가 아니라 따로 둔 폴더에 두기를 권합니다([노트는 앱과 따로 두기](#노트는-앱과-따로-두기)).

## 바로 띄우기

외부 의존성이 없어 `npm install` 없이 실행합니다.

```sh
git clone https://github.com/kakao-hash-table/pkm-app.git
cd pkm-app
npm start
```

브라우저에서 http://127.0.0.1:5270 을 엽니다.

처음 열면 프로필 "개인"이 만들어지고, 데이터 폴더(기본 `./data`)에 아래 폴더가 생깁니다.

```
data/개인/
  00_인박스/
  01_지식/
  02_시간/
  03_행동/
  _템플릿/
  _설정.md
```

화면의 [메모하기]로 아무 줄이나 담아 보세요. 0.5초 뒤 `data/개인/00_인박스/` 아래에 날짜와 첫 줄을 이름으로 한 `.md` 파일이 생깁니다. 앱은 바뀐 파일만 저장하고, 지운 노트는 그 프로필의 `.trash/`로 옮깁니다.

여기까지는 시험용으로 `./data`에 저장됩니다. 계속 쓸 거라면 [노트는 앱과 따로 두기](#노트는-앱과-따로-두기)대로 데이터 폴더를 옮기세요.

## 화면

| 화면 | 하는 일 |
|---|---|
| 지금 | 지금 시각에 할 것만 카드로 보여 줍니다. 할 일은 끝냈다·나중에, 루틴은 했다·건너뛰기. 시간이 지났는데 체크하지 않은 오늘 루틴도 카드로 묻습니다. 하루 시작보다 늦게 열면 그날 시작을 옮길지 묻습니다 |
| 인박스 | 무엇이든 먼저 담고, 나중에 할 일이나 노트로 보냅니다 |
| 지식 | 참조노트, 임시노트, 영구노트, 맥락노트 |
| 시간 | 계획(어느 날이든 블록 시간표 — 약속, 루틴, 비워 둘 시간을 먼저 놓고 남는 시간을 "빈 시간" 블록으로 나눠 할 일을 채움. 인박스, 지식, 시간, 행동 블록도 여기에), 데일리, 여러 날 돌아보기, 직접 만드는 기록 종류(회의록, 여행, 요리 등) |
| 행동 | 단기(대기, 진행, 기다림, 완료), 장기(누적 기록), 루틴, 약속 |

프로필(예: 개인, 회사)마다 데이터가 따로 저장됩니다. 모바일과 PC, 라이트와 다크 모드를 지원합니다. 약속은 [구글 캘린더](#구글-캘린더)와 양방향으로 맞출 수 있습니다.

## 노트는 앱과 따로 두기

`./data`는 git에서 제외되어 있어 실수로 커밋되지는 않습니다. 대신 백업도 동기화도 되지 않습니다. 노트를 비공개 저장소에 따로 두면 [GitHub 자동 동기화](#저장-위치)로 백업할 수 있고, 앱을 새로 받거나 업데이트해도 노트는 그대로입니다.

권장 배치는 이렇습니다.

```
~/pkm-app    이 저장소
~/pkm-data   내 노트 (비공개 git 저장소)
```

`~/pkm-data`에서 `git init`을 하고 비공개 원격 저장소를 연결해 둔 뒤, `~/pkm-app`에서 데이터 폴더를 지정해 실행합니다.

```sh
PKM_DATA=../pkm-data npm start
```

이미 `./data`에 만든 노트는 프로필 폴더째 옮기면 됩니다.

```sh
mv data/개인 ../pkm-data/
```

## Obsidian과 함께 쓰기

데이터 폴더 안의 프로필 폴더(예: `pkm-data/개인`)를 Obsidian 볼트로 엽니다. Obsidian에서 파일을 고치면 앱이 15초 안에 다시 불러옵니다.

앱의 [Obsidian에서 편집] 버튼은 볼트 이름이 프로필 이름과 같을 때 그 노트를 엽니다.

노트는 프런트매터와 `# 제목` 칸으로 이루어집니다. 프런트매터의 값은 영어 키(`type`, `status` 등)로 저장되고, 화면에는 한국어로 보입니다. 형식은 `web/js/pkm-md.js`에 있고(브라우저와 Node가 함께 씀), 각 프로필의 `_설정.md`에 있는 `format: 1`이 형식 버전입니다.

## 저장 위치

노트는 파일로만 저장합니다. 브라우저 안에 저장하는 방식은 두지 않습니다(기기마다 갈라지고, 사이트 데이터를 지우면 사라지기 때문입니다).

| 앱을 연 방법 | 저장 위치 | 동작 |
|---|---|---|
| 로컬 서버 (`npm start`) | 이 컴퓨터 (기본) | 데이터 폴더의 파일에 바로 저장합니다 |
| 로컬 서버 | GitHub 자동 동기화 | 데이터 폴더가 git 저장소이고 원격 `origin`이 있으면, 저장 8초 뒤 그 프로필 폴더만 커밋하고 푸시합니다. 2분마다 원격에서 받아 옵니다 |
| 정적 파일 (`web/` 폴더를 정적 호스팅) | GitHub 저장소 (베타) | 처음 열면 GitHub 연결 화면이 나옵니다. 개인 토큰으로 연결하고 저장소를 고르면, 브라우저가 그 저장소의 프로필 폴더(`<프로필>/`, 없고 `data/<프로필>/`이 있으면 그곳)에 직접 저장합니다. 로컬 서버와 같은 저장소를 함께 쓸 수 있습니다 |

로컬 서버로 열었을 때는 프로필마다 앱의 프로필 › 저장 위치에서 위 두 가지 중에 고릅니다.

GitHub에 저장하는 두 방식은 비공개 저장소에만 쓰세요. 토큰은 Fine-grained 토큰으로, 저장소 하나에 Contents 읽기/쓰기 권한만 줍니다. 토큰은 그 브라우저에만 저장됩니다. 정적 파일 방식은 실제 저장소로 시험하지 않아서 베타로 표시합니다.

내보내기(zip)와 가져오기(폴더의 `.md` 파일)도 저장 위치 창에 있습니다.

## 구글 캘린더

로컬 서버로 열었을 때 프로필마다 구글 캘린더를 연결합니다. 연결하면 캘린더 일정이 약속으로 들어오고, pkm에서 만들거나 고치거나 지운 약속도 캘린더에 반영됩니다.

처음 한 번은 내 구글 클라우드 프로젝트에 OAuth 클라이언트가 있어야 합니다.

1. [Google Calendar API](https://console.cloud.google.com/apis/library/calendar-json.googleapis.com)를 사용 설정합니다.
2. [OAuth 동의 화면](https://console.cloud.google.com/auth/overview)을 만들고 테스트 사용자에 내 구글 계정을 넣습니다.
3. [사용자 인증 정보](https://console.cloud.google.com/apis/credentials)에서 OAuth 클라이언트 ID를 만듭니다. 애플리케이션 유형은 **데스크톱 앱**입니다.
4. 앱의 행동 › 약속 › [구글 캘린더 연결하기]에 클라이언트 ID와 보안 비밀번호를 넣고, 구글로 로그인해 권한을 허용합니다.

| 항목 | 동작 |
|---|---|
| 맞추는 때 | 2분마다, 그리고 약속을 저장하고 3초 뒤. 서버가 맞추므로 화면을 닫아도 돕니다 |
| 맞추는 범위 | 지난 30일부터 앞으로 180일까지의 기본 캘린더 일정 |
| 맞추는 칸 | 제목, 시작, 끝, 장소. 메모는 pkm에만 남깁니다. 참석자는 캘린더에서 가져오기만 하고 보내지 않습니다(남에게 초대 메일이 가지 않게) |
| 양쪽이 다 바뀌면 | 캘린더 쪽을 따릅니다 |
| 지울 때 | 캘린더에서 지운 일정은 pkm의 `.trash/`로, pkm에서 지운 약속은 캘린더에서도 지웁니다. 한 번에 10개보다 많이 지워야 하면 캘린더에서는 지우지 않고 알립니다 |
| 가져오지 않는 것 | 하루 종일 일정 |
| 연결 전에 만든 약속 | 캘린더로 보내지 않습니다 |

클라이언트 정보와 로그인 토큰은 노트 폴더가 아니라 `~/.pkm-app/gcal.json`(권한 0600)에 둡니다. 노트 폴더는 GitHub로 올라갈 수 있기 때문입니다. 위치는 `PKM_APP_HOME`으로 바꿉니다. [연결 끊기]를 누르면 이 파일에서 토큰을 지우고 구글 쪽 권한도 거둡니다. 가져온 약속은 그대로 남습니다.

## 실행 옵션

| 환경변수 | 기본값 | 뜻 |
|---|---|---|
| `PKM_DATA` | `./data` | 데이터 폴더 |
| `PORT` | `5270` | 포트 |
| `HOST` | `127.0.0.1` | 여는 주소 |

포트만 바꿀 때는 `scripts/serve.sh [포트]`도 됩니다.

## 보안

서버는 기본으로 127.0.0.1에만 열리고 로그인이 없습니다. 인터넷에 그대로 열지 마세요. 휴대폰에서 쓰려면 Tailscale 같은 사설망으로 내 기기에서만 열기를 권합니다.

## 템플릿

노트 템플릿의 원본은 `templates/`에 있습니다. 서버를 켤 때마다 각 프로필의 `_템플릿/`을 원본에 맞추므로, 앱을 업데이트하면 템플릿도 따라옵니다.

이때 원본과 같은 이름의 파일만 덮어씁니다. 프로필에서 만든 기록 종류 템플릿은 그대로 남습니다.

## 폴더 구조

```
web/index.html        앱
web/js/pkm-md.js      저장 형식
web/js/pkm-store.js   저장소 (서버, 브라우저, GitHub)
web/prototype/        디자인 목업, SPEC.md(설계 스펙), REVIEW.md(디자인 검수)
server/index.js       로컬 서버, API, git 동기화
server/gcal.js        구글 캘린더 양방향 동기화
templates/            노트 템플릿 원본
scripts/serve.sh      실행 스크립트
test/                 시험 (node:test)
```

## 개발

```sh
npm test
```

저장 형식 왕복, 서버, 자동 동기화, 구글 캘린더 동기화(가짜 구글 서버로)를 시험합니다.

설계 원칙은 `web/prototype/SPEC.md` §0에 있습니다. 특정 직업이나 도메인에서만 쓰는 타입은 코드에 넣지 않고 템플릿과 기록 종류로 풉니다.
