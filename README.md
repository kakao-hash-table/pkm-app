# pkm-app

노트, 하루 시간표, 할 일을 한 화면에서 다루는 개인 지식관리(PKM) 웹 앱입니다. 노트는 Obsidian과 함께 쓸 수 있는 마크다운 파일로 저장됩니다.

Node 20 이상만 있으면 바로 띄울 수 있습니다. 노트는 이 저장소가 아니라 따로 둔 폴더에 두기를 권합니다([노트는 앱과 따로 두기](#노트는-앱과-따로-두기)).

## 바로 띄우기

외부 의존성이 없어 `npm install` 없이 실행합니다.

```sh
git clone https://github.com/kakao-hash-table/pkm-app.git
cd pkm-app
npm start
```

브라우저에서 http://127.0.0.1:5270 을 엽니다.

처음 열면 프로필 "개인"이 만들어지고, 데이터 폴더(기본 `./data`)에 아래 폴더가 생깁니다.

```
data/개인/
  00_인박스/
  01_지식/
  02_시간/
  03_행동/
  _템플릿/
  _설정.md
```

화면의 [메모하기]로 아무 줄이나 담아 보세요. 0.5초 뒤 `data/개인/00_인박스/` 아래에 날짜와 첫 줄을 이름으로 한 `.md` 파일이 생깁니다. 앱은 바뀐 파일만 저장하고, 지운 노트는 그 프로필의 `.trash/`로 옮깁니다.

여기까지는 시험용으로 `./data`에 저장됩니다. 계속 쓸 거라면 [노트는 앱과 따로 두기](#노트는-앱과-따로-두기)대로 데이터 폴더를 옮기세요.

## 화면

| 화면 | 하는 일 |
|---|---|
| 오늘 | 하루 시간표. 약속, 루틴, 비워 둘 시간을 먼저 놓고 남는 시간을 "빈 시간" 블록으로 나눠 할 일을 채웁니다. 인박스, 지식, 시간, 행동 블록도 여기에 놓습니다 |
| 인박스 | 무엇이든 먼저 담고, 나중에 할 일이나 노트로 보냅니다 |
| 지식 | 참조노트, 임시노트, 영구노트, 맥락노트 |
| 시간 | 데일리, 여러 날 돌아보기, 직접 만드는 기록 종류(회의록, 여행, 요리 등) |
| 행동 | 단기(대기, 진행, 기다림, 완료), 장기(누적 기록), 루틴, 약속 |

프로필(예: 개인, 회사)마다 데이터가 따로 저장됩니다. 모바일과 PC, 라이트와 다크 모드를 지원합니다. 구글 캘린더 연동은 아직 없습니다.

## 노트는 앱과 따로 두기

`./data`는 git에서 제외되어 있어 실수로 커밋되지는 않습니다. 대신 백업도 동기화도 되지 않습니다. 노트를 비공개 저장소에 따로 두면 [GitHub 자동 동기화](#저장-위치)로 백업할 수 있고, 앱을 새로 받거나 업데이트해도 노트는 그대로입니다.

권장 배치는 이렇습니다.

```
~/pkm-app    이 저장소
~/pkm-data   내 노트 (비공개 git 저장소)
```

`~/pkm-data`에서 `git init`을 하고 비공개 원격 저장소를 연결해 둔 뒤, `~/pkm-app`에서 데이터 폴더를 지정해 실행합니다.

```sh
PKM_DATA=../pkm-data npm start
```

이미 `./data`에 만든 노트는 프로필 폴더째 옮기면 됩니다.

```sh
mv data/개인 ../pkm-data/
```

## Obsidian과 함께 쓰기

데이터 폴더 안의 프로필 폴더(예: `pkm-data/개인`)를 Obsidian 볼트로 엽니다. Obsidian에서 파일을 고치면 앱이 15초 안에 다시 불러옵니다.

앱의 [Obsidian에서 편집] 버튼은 볼트 이름이 프로필 이름과 같을 때 그 노트를 엽니다.

노트는 프런트매터와 `# 제목` 칸으로 이루어집니다. 프런트매터의 값은 영어 키(`type`, `status` 등)로 저장되고, 화면에는 한국어로 보입니다. 형식은 `web/js/pkm-md.js`에 있고(브라우저와 Node가 함께 씀), 각 프로필의 `_설정.md`에 있는 `format: 1`이 형식 버전입니다.

## 저장 위치

프로필마다 앱의 프로필 › 저장 위치에서 고릅니다.

| 앱을 연 방법 | 저장 위치 | 동작 |
|---|---|---|
| 로컬 서버 | 이 컴퓨터 (기본) | 데이터 폴더의 파일에 바로 저장합니다 |
| 로컬 서버 | GitHub 자동 동기화 | 데이터 폴더가 git 저장소이고 원격 `origin`이 있으면, 저장 8초 뒤 그 프로필 폴더만 커밋하고 푸시합니다. 2분마다 원격에서 받아 옵니다 |
| 정적 파일 (`web/` 폴더를 정적 호스팅) | 이 브라우저 | 브라우저 localStorage에 저장합니다 |
| 정적 파일 | GitHub 토큰 (베타) | 개인 토큰으로 브라우저가 GitHub 저장소의 프로필 폴더(`<프로필>/`, 없고 `data/<프로필>/`이 있으면 그곳)에 직접 저장합니다. 로컬 서버와 같은 저장소를 함께 쓸 수 있습니다 |

GitHub에 저장하는 두 방식은 비공개 저장소에만 쓰세요. 토큰은 Fine-grained 토큰으로, 저장소 하나에 Contents 읽기/쓰기 권한만 줍니다. 토큰 방식은 실제 저장소로 시험하지 않아서 베타로 표시합니다.

내보내기(zip)와 가져오기(폴더의 `.md` 파일)도 저장 위치 창에 있습니다.

## 실행 옵션

| 환경변수 | 기본값 | 뜻 |
|---|---|---|
| `PKM_DATA` | `./data` | 데이터 폴더 |
| `PORT` | `5270` | 포트 |
| `HOST` | `127.0.0.1` | 여는 주소 |

포트만 바꿀 때는 `scripts/serve.sh [포트]`도 됩니다.

## 보안

서버는 기본으로 127.0.0.1에만 열리고 로그인이 없습니다. 인터넷에 그대로 열지 마세요. 휴대폰에서 쓰려면 Tailscale 같은 사설망으로 내 기기에서만 열기를 권합니다.

## 템플릿

노트 템플릿의 원본은 `templates/`에 있습니다. 서버를 켤 때마다 각 프로필의 `_템플릿/`을 원본에 맞추므로, 앱을 업데이트하면 템플릿도 따라옵니다.

이때 원본과 같은 이름의 파일만 덮어씁니다. 프로필에서 만든 기록 종류 템플릿은 그대로 남습니다.

## 폴더 구조

```
web/index.html        앱
web/js/pkm-md.js      저장 형식
web/js/pkm-store.js   저장소 (서버, 브라우저, GitHub)
web/prototype/        디자인 목업, SPEC.md(설계 스펙), REVIEW.md(디자인 검수)
server/index.js       로컬 서버, API, git 동기화
templates/            노트 템플릿 원본
scripts/serve.sh      실행 스크립트
test/                 시험 (node:test)
```

## 개발

```sh
npm test
```

저장 형식 왕복, 서버, 자동 동기화를 시험합니다.

설계 원칙은 `web/prototype/SPEC.md` §0에 있습니다. 특정 직업이나 도메인에서만 쓰는 타입은 코드에 넣지 않고 템플릿과 기록 종류로 풉니다.
