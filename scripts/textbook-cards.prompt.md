# 교과서 노트 → 짧은 카드 (SPEC §0-2)

휴대폰에서 한 장씩 넘기며 공부할 카드를 만든다. 교과서 노트 하나를 영구노트 모양의 카드 여러 장으로 다시 쓴다.

## 입력
일감 JSON 파일 하나: `[{ id, title, book, chapter, body }, …]`. `title`은 노트의 주장 한 줄, `body`는 노트 본문(`# 내용`·`# 연결`·`# 활용`·`# 출처`).

## 출력
같은 순서로 `[{ id, cards: [{ title, q, body }, …] }, …]` JSON 파일 하나. 다른 말은 쓰지 않는다.

## 카드 한 장
- **title** — 주장 한 문장. 그것만 읽어도 뜻이 통한다. 45자 이내, 마침표 없이, 원문과 같은 말투(해라체: "~다").
  - 좋음: "세게 칠 때도 쥐는 힘은 그대로 둔다" / 나쁨: "그립의 힘"(주제일 뿐 주장이 아니다)
- **q** — 복습 때 먼저 보여 줄 질문. 답이 title이다. 30자 이내, 물음표로 끝낸다. 답이 되는 말을 질문에 넣지 않는다. 한 가지만 묻는다(무엇·언제·왜·어떻게 중 하나).
  - 좋음: title "세게 칠 때도 쥐는 힘은 그대로 둔다" → q "세게 치고 싶을 때 쥐는 힘은 어떻게 하나?" / 나쁨: "그립은 왜 가볍게 쥐나?"(답 '가볍게'가 질문에 있다)
- **body** — title을 되풀이하지 않고 왜 그런지·어떻게 하는지부터 쓴다. 예는 원문에 있는 것만 쓴다(없으면 쓰지 않는다). 1~3문장, 200자 이내(코드는 따로 4줄까지).
- 카드는 한 장씩 따로 복습에 나온다. "이것"·"위의"·"앞 장" 없이 한 장만 읽어도 통하게 쓴다. 위치·각도·힘은 무엇을 기준으로 재는지 같이 쓴다(예: "아래팔이 바닥과 수직인 자리"). 한 장에 새 용어는 3개까지.
- 카드 한 장에 생각 하나. 두 가지를 말하고 있으면 둘로 나눈다.

## 한 노트에서
- 3~6장(내용이 짧으면 2장도 된다). 노트 순서를 따른다.
- 첫 장은 노트 제목의 주장을 그대로 담는다(짧게 다듬어도 된다).
- `# 내용`과 `# 활용`을 카드로 만든다. 활용은 "해 볼 것" 카드로 쓴다. title은 "~할 때 ~한다" 꼴(언제 → 무엇)로, body에 몇 번 하는지와 무엇을 확인하는지를 쓴다. 좋음: "그립을 잡을 때 손가락 힘을 10단계 중 3 이하로 둔다". `# 연결`·`# 출처`는 카드로 만들지 않는다(앱이 원문 노트로 이어 준다).
- 원문이 바로잡아 주는 오해("~라는 오해")가 있으면 바른 쪽을 주장으로 쓴 카드 한 장.
- 표는 꼭 알아야 할 줄만 카드로. 다 옮기지 않는다.

## 지킬 것 — 어기면 검사에서 떨어진다
- **원문에 없는 사실을 더하지 않는다.** 숫자·단위·이름·용어는 원문 그대로. 원문에 없는 숫자를 쓰지 않는다(계산해서 새 숫자를 만들지도 않는다).
- `[[링크]]`는 원문에 있는 것만, 꼭 필요할 때만.
- 원문이 단정하지 않은 것(“~라고 한다”, “포켓볼 기준”)은 카드에서도 단정하지 않는다.
- `# 출처`에 붙은 범위 표시("포켓볼 기준" 등)는 버리지 않는다. 첫 장 body 끝에 괄호로 옮긴다.
- 장식 이모지·느낌표를 쓰지 않는다.
